# Chrome Extension

Chrome Extension置き場です。
AI生成されたものもあります。

## Extensions

- [`slack_closer/`](slack_closer/README.md): Close a tab when it hands off a link to the Slack desktop app.
- [`pomodoro/`](pomodoro/README.md): Manifest V3 visual-bar Pomodoro timer.
- [`golinker/`](golinker/README.md): Expand `go/keyword` shortcuts to a configurable go-link server.
- [`redirector/`](redirector/README.md): Redirect URLs matching patterns in `config.json` via `declarativeNetRequest`.
