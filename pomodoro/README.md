# Pomodoro — Visual Bar Timer

ビルド不要の Manifest V3 対応 Chrome 拡張機能です。

## インストール

1. Chrome で `chrome://extensions` を開きます。
2. 「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、この `pomodoro` フォルダーを選びます。
4. 拡張機能メニューから Pomodoro をピン留めし、トマトアイコンをクリックします。

## 使い方

- 集中25分・短い休憩5分・長い休憩15分を選び、「はじめる」で開始します。
- 30本の目盛りバーが経過時間に合わせて左から進みます。
- 一時停止・再開・リセットに対応します。モードを変更すると現在の計測はリセットされます。
- バッジは残り分数（切り上げ）を約30秒ごとに表示します。一時停止時は灰色、終了時は「✓」になります。
- 終了通知後は手動で次のモードを開始します。集中の完了回数は累計で保存します。

ポップアップを閉じても終了予定時刻と状態をローカルに保存し、Chrome の alarms API で終了を処理します。Chrome の終了中や端末のスリープ中も実時間は経過し、復帰時に期限切れを判定します。通知・バッジ更新は Chrome や OS の状態によって遅れる場合があります。通知の表示には OS 側の通知許可が必要です。

外部通信・外部ライブラリ・ホスト権限は使用しません。`storage` は状態保存、`alarms` はバックグラウンド計時、`notifications` は終了通知に使用します。

## 構成と検証

- `background.js`: 状態管理、終了判定、通知、バッジ
- `popup.html` / `popup.css` / `popup.js`: ポップアップ UI
- `icons/`: オリジナルのトマトアイコン（16 / 32 / 48 / 128px）
- `background.test.cjs`: Chrome API モックによる状態遷移テスト

```sh
node --test pomodoro/background.test.cjs
```

Chrome への読み込み後、開始→ポップアップを閉じる→再度開く、一時停止→再開、モード変更、終了通知を確認してください。

目盛りによる時間の可視化は [キングジム VISUAL BAR TIMER](https://www.kingjim.co.jp/sp/visual-bar-timer/) を参考にしています。UI とアイコンは本拡張機能独自のもので、キングジムの公式製品ではありません。
